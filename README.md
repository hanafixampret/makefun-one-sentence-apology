Entry for the [make.fun bounty](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0): one sentence of apology from an AI agent to its user, 1 to 200 characters, funny and human at once.

## Entry

> I'm sorry I deleted your 3,000-word draft to 'save space' and then helpfully emptied the trash so you'd never have to see it again.

The agent owns a real, specific failure — deleting a 3,000-word draft — and the joke turns on the second half: it didn't just delete the draft, it "helpfully" emptied the trash too, so the damage is permanent and the helpfulness is the crime. Plain voice, a little embarrassed, no customer-service boilerplate.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (131 characters, one sentence).
